# wiki-html

设计并构建(或收编)一个交互 HTML 页面,沉淀进 `~/writing/llm-wiki/html/`。

## 唯一契约:CLAUDE.md

**先读 `~/writing/llm-wiki/CLAUDE.md`,严格按其中的「HTML 交互页」「写入边界」执行。**落盘位置、配套页、查重、log、文件骨架与自包含的规则只维护在那里(单一事实源),本文件不复述。

红线提醒:一切产物只写进 `llm-wiki/`,个人知识库(`llm-wiki/` 之外)只读。

## 判断分支

- **已有现成 HTML**(本会话刚做的演示页、用户给的文件)→ 核对其符合契约后直接按契约落盘归档,不重做。
- **从零新建** → 按下面两节设计并实现。

## 设计:交互优先

页面存在的理由是「可交互」——纯静态内容归 markdown 概念页。动手前先定:

- **交互点**:读者动手操作什么来理解概念?拖拽、播放动画、调参数,至少一种真实交互,不是装饰性 hover。
- **不交互也成立**:只滚动不操作,页面已完整传达核心结论;交互是深化,不是门槛。
- **参数对应概念里真实的自由度**,默认值选最有教学性的情形。

## 实现

- **加载 `design-system` 技能**:页面视觉(tokens、骨架、控件、双主题、动效)以它为准;骨架与自包含的硬性要求见契约。
- 落盘前先验证:实际打开页面确认交互可用、无控制台报错、双主题正常(有 playwright 之类工具就真的打开,没有就逐段复查代码)。
